# Unity RPG Projekt (Prototyp)

Dieses Projekt entstand aus persönlichem Interesse an Game Development.  
Es handelt sich um einen frühen Prototyp eines inspirierten MMORPGs, umgesetzt in Unity.

## 📌 Projektstatus

Dieses Projekt befindet sich in einem unfertigen Zustand („Work in Progress“) und dient vor allem zum Erlernen von Unity, C# und allgemeinen Game-Dev-Konzepten.  
Die Assets stammen aus frei verfügbaren Unity Asset Packs und wurden größtenteils zu Testzwecken eingebunden.

## ⚙️ Verwendete Technologien

- Unity (Version 2022.3.31f1)
- C#
- Shader Graph (grundlegend)
- Unity Asset Store (verschiedene kostenlose Assets)
- Git (minimaler Einsatz)

## 💡 Lernziele / Inhalte

- Szenenaufbau, Navigation und UI-Elemente
- Erste Gameplay-Mechaniken (z. B. Bewegung, Interaktionen)
- Arbeiten mit prefabs, Komponenten und einfachen Skripten
- Erste Erfahrungen mit Projektstruktur und Versionsverwaltung

## 🔎 Hinweise

- Der Code ist in weiten Teilen experimentell und spiegelt ein frühes Lernstadium wider.
- Die Struktur der Assets und Ordner ist nicht final oder „clean“.
- Einige eingebundene Assets wurden nur ausprobiert und nicht aktiv genutzt.
